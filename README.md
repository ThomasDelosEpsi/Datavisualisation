# Datavisualisation

Script Python générant une carte choroplèthe interactive (Folium) des résultats d'élections par commune en Savoie / Haute-Savoie, à partir de données de vote (CSV) croisées avec un fond de carte géographique des communes.

## Stack

- Python
- pandas, geopandas, folium

## Usage

```
python Dashboard.py
```

Génère un fichier HTML contenant la carte interactive.
